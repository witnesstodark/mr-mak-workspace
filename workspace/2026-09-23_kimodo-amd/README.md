# Kimodo AMD Motion Studio

Local text-to-motion generation for the AMD Radeon RX 7900 XTX using the
Kimodo.cpp Windows Vulkan port. The runtime lives in
`projects/kimodo-amd/runtime`; this card records the reproducible setup and
launch path without committing third-party source or model weights.

Run `projects/kimodo-amd/setup-windows.ps1` to install or rebuild it, then open
the browser studio at `http://127.0.0.1:8094`.
